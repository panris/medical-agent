## 设计规范参考

### 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| `--brand` | `#0d9488` | 主色、用户气泡、CTA |
| `--brand-dark` | `#0f766e` | hover 态 |
| `--brand-light` | `#ccfbf1` | 标签、助手头像背景 |
| `--bg` | `#f0f4f8` | 页面背景 |
| `--text-primary` | `#0f172a` | 正文 |
| `--text-secondary` | `#64748b` | 辅助文字 |

### 间距

- 消息间距：`20px`
- 容器内边距：移动端 `16px`，桌面端 `32px`
- 圆角：小 `8px`、中 `12px`、大 `16px`、输入框 `20px`

### 字体

- 主字体：DM Sans（Google Fonts）
- 正文 `14px`，输入框 `15px`，标题 `16–22px`
